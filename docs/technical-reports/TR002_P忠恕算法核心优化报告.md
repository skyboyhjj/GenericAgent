## 一、算法概述

### 1.1 核心概念

**P忠恕**：P = Position（位置/姿态/潜能）+ 忠恕（儒家核心，来自《论语》"夫子之道，忠恕而已矣"）

定义：在时空因缘的某一点上，生命所呈现出的、以"忠恕"为内核的道德位置、精神姿态与成长潜能。

### 1.2 四维模型

| 维度        | 名称      | 含义                         | 权重 |
| ----------- | --------- | ---------------------------- | ---- |
| T（时位轴） | Temporal  | 时间维度——及时性、时机把握   | 0.20 |
| S（宇位轴） | Spatial   | 空间维度——位置安排、环境适应 | 0.20 |
| C（识位轴） | Wisdom    | 智慧维度——认知理解、智慧觉察 | 0.30 |
| R（缘位轴） | Causality | 因果维度——关系处理、忠恕之道 | 0.30 |

### 1.3 基本公式

```
P忠恕 = T×0.2 + S×0.2 + C×0.3 + R×0.3
```

**权重哲学**：
- 识位轴(0.3)最高 → 道家"明智"原则：智慧是第一推动力
- 缘位轴(0.3)并重 → 儒家"忠恕"原则：人际关系是核心修为
- 时位轴(0.2) + 宇位轴(0.2) → 时空情境是外在条件，不决定本质

## 二、优化历程

### 2.1 原始版本（v1.0）

**问题**：简单的加权公式，但缺乏直觉化和道儒融合深度。

```javascript
// v1.0 基本公式
const P = T * 0.2 + S * 0.2 + C * 0.3 + R * 0.3;
```

### 2.2 廿七章优化（v2.0）

**优化原则**：遵循《道德经》第27章"善数不用筹策"——善算者不用计算工具。算法应更直觉化，减少数学复杂度。

**核心改进**：

```javascript
class ZhongShuCalculator {
  
  // ② 优化：简化的直觉算法
  calculateIntuitiveScore(temporal, spatial, wisdom, causality) {
    // 智慧与因果构成内在核心
    const intuitionScore = wisdom * 0.4 + causality * 0.3;
    // 时空情境构成外在条件
    const situationalScore = (temporal + spatial) * 0.3;
    return intuitionScore + situationalScore;
  }
  
  // ③ 优化：道家哲学解释版
  calculateDaoistScore(temporal, spatial, wisdom, causality) {
    const daoistWeight = wisdom * 0.5;        // 道家智慧为主导
    const confucianWeight = causality * 0.3;   // 儒家忠恕居次
    const situationalWeight = (temporal + spatial) * 0.2; // 时空情境
    return daoistWeight + confucianWeight + situationalWeight;
  }
}
```

**权重对比**：

| 维度    | v1.0 | v2.0直觉版 | v2.0道家版 | 变化原因         |
| ------- | ---- | ---------- | ---------- | ---------------- |
| C(识位) | 0.30 | 0.40       | 0.50       | 提升智慧主导地位 |
| R(缘位) | 0.30 | 0.30       | 0.30       | 维持忠恕核心     |
| T(时位) | 0.20 | 0.15       | 0.10       | 降低外在条件影响 |
| S(宇位) | 0.20 | 0.15       | 0.10       | 同上             |

## 四、阴阳平衡度算法

### 4.1 设计原理

将四维分为阴阳两大类：
- **阳（显化层）**：T(时位) + S(宇位) — 外在的时空条件
- **阴（内在层）**：C(识位) + R(缘位) — 内在的智慧与关系

### 4.2 实现

```javascript
calculateBalance(temporal, spatial, wisdom, causality) {
    const yangScore = temporal + spatial;    // 阳：外在显化
    const yinScore = wisdom + causality;      // 阴：内在本质
    
    // 阴阳平衡度：越接近1越平衡
    const balanceRatio = Math.min(yangScore / yinScore, 
                                   yinScore / yangScore);
    return Math.round(balanceRatio * 10);
}
```

**解读**：
- balanceScore ≥ 8：阴阳调和——内在修为与外在行动高度一致
- balanceScore 5-7：偏阴或偏阳——需要调和
- balanceScore < 5：严重失衡——需要重点关注

## 五、用户画像分类

### 5.1 九型画像矩阵

基于阳形态（行为模式）× 阴质地（能量状态）构成 3×3 = 9种用户画像：

```
阳形态（行为特征）
├── 行者型：持久性 > 8，完整性 > 8 → 行动力强，持续输出
├── 悟者型：及时性 > 8，连贯性 > 8 → 悟性高，善于把握时机
└── 习者型：其他情况 → 需要练习积累

阴质地（能量状态）
├── 清明之境：总分 > 8，平衡 > 8 → 高能量高和谐
├── 砥砺之境：总分 6-8 → 中等能量，持续精进中
└── 蓄养之境：总分 < 6 → 处于积累期，需要滋养
```

### 5.2 实现

```javascript
getUserProfile(balanceScore, overallScore, behavioralPattern) {
    let yangType = '';
    if (behavioralPattern.persistence > 8 && 
        behavioralPattern.completeness > 8) {
        yangType = '行者型';
    } else if (behavioralPattern.timeliness > 8 && 
               behavioralPattern.coherence > 8) {
        yangType = '悟者型';
    } else {
        yangType = '习者型';
    }
    
    let yinType = '';
    if (overallScore > 8 && balanceScore > 8) {
        yinType = '清明之境';
    } else if (overallScore > 6) {
        yinType = '砥砺之境';
    } else {
        yinType = '蓄养之境';
    }
    
    return {
        profile: `${yangType} + ${yinType}`,
        yang: yangType,
        yin: yinType,
    };
}
```
